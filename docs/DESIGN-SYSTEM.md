# 视觉基调、品牌与设计系统

> 配套 `UI-SPEC.md`（结构与交互）与 `../ARCHITECTURE.md`（技术约束）。本文定义「长什么样、为什么这样、如何落地成 token」。
> 状态：v0.2 已实施。色值已用 WCAG 公式核算对比度（`python scripts/check-contrast.py`），并已在真机深浅主题下截图（`docs/screenshots/`）；未做色觉模拟验证。

## 1. 品牌定位

### 1.1 一句话

**一间安静的制片台。**

不是「AI 魔法工厂」，不是「创作社区」，不是「效率仪表盘」。它是一个你坐下来就能干活的地方：桌面干净、光线稳定、工具在伸手可及的位置。

### 1.2 品牌关键词

| 要 | 不要 |
|---|---|
| 克制（quiet） | 炫技、发光、粒子 |
| 可信（trustworthy） | 夸张承诺、"一键爆款" |
| 有手感（tactile） | 纯扁平、无反馈 |
| 专业（craft） | 玩具感、卡通 |
| 本地（local） | 云端万能论 |

### 1.3 与竞品的视觉区隔

| 常见 AI 产品 | 我们 |
|---|---|
| 紫蓝渐变、星光、机器人 | 暖灰纸面 + 墨绿强调色 |
| 深色赛博界面 | 默认浅色，深色是平等选项而非"专业模式" |
| 巨大聊天框居中 | 三栏工作台，聊天只是右栏的一小块 |
| 动效炫技 | 动效只用于解释状态变化 |
| 英文优先 | 中文排版优先，字号与行高按中文调 |

### 1.4 命名方向（三选一，待定）

| 方向 | 示例 | 气质 | 风险 |
|---|---|---|---|
| 工作台 | 制片台 / 创作台 | 稳、直白 | 略普通，商标拥挤 |
| 手艺人 | 稿台 / 案头 | 有质感、文艺 | 认知成本高 |
| 伙伴 | 副手 / 二稿 | 亲切 | 容易滑向"AI 助手"俗套 |

建议：**主名走"台"字系，副标题说明用途**。例如「稿台 · 创作者的 AI 制片台」。最终命名需查商标与域名，本文不代替法务。

## 2. 设计原则（视觉层）

1. **内容占 70%**：界面 chrome 退后，颜色只用在状态与行动上。
2. **一屏一个主动作**：每个页面只有一个实心强调按钮，其余为次级。
3. **状态用色，装饰不用色**：颜色是信息，不是氛围。
4. **边界靠留白，不靠线**：优先用间距分组，其次用浅描边，最后才用卡片阴影。
5. **中文优先排版**：行高更松、字重更轻、标点避头尾。
6. **可读性优先于密度**：默认舒适密度；重度用户可切紧凑。
7. **深浅色等价**：两套主题都必须是"设计过的"，不做简单反色。

## 3. 色彩系统

### 3.1 色相选择理由

- 中性色偏暖（黄灰），不偏蓝：长时间阅读不刺眼，且与"纸/稿"的隐喻一致；同时避开所有 AI 产品都在用的冷灰蓝。
- 强调色墨绿（teal-green）：与"红=危险、黄=警告"区分明确，色觉障碍下仍可与红区分；比蓝色更少见于同类产品。
- 语义色只用于状态，不用于品牌装饰。

### 3.3 状态浅底

徽标底色用 `color-mix(in oklab, var(--ok) 12%, var(--surface))`，文字用对应语义色。禁止直接调透明度，避免在不同底色上失真。

### 3.4 使用规则

- 强调色面积不超过屏幕 5%。
- 同屏最多两种语义色（例如 warn + danger），超过说明信息架构有问题。
- 不用纯黑 `#000` 与纯白 `#FFF` 作文本/背景（已用暖黑与米白替代）。
- 图表配色按语义顺序：accent → info → warn → danger，并提供图案/线型作为第二编码。

## 4. 字体与排版

### 4.1 字族

```css
--font-sans: -apple-system, "Segoe UI", "PingFang SC", "Hiragino Sans GB",
             "Microsoft YaHei UI", "Noto Sans SC", sans-serif;
--font-serif: "Songti SC", "STSong", "SimSun", "Noto Serif SC", Georgia, serif;
--font-mono: "JetBrains Mono", "Cascadia Code", "SF Mono", Consolas, monospace;
```

三条实测结论（Windows 11 / Chromium 143，用 `measureText` 与截图比对得出）：

1. **正文用无衬线，不用宋体**。15–16px 下宋体笔画过细、横竖对比大，长时间阅读疲劳；SimSun 的小字号渲染尤其差。`.manuscript` 一律用 `--font-sans`。
2. **衬线只用于品牌字标与标题装饰**。`--font-serif` 限定在 wordmark、封面预览、引文块（`blockquote`）三处，正文与 UI 不用。
3. **字体回退按实测顺序**。Windows 上 `Songti SC`/`STSong` 会回落成 SimSun（两者 `measureText` 宽度都是 80），macOS 上命中真正的 Songti。因此衬线串必须把 `Songti SC` 放最前，避免 Windows 拿到 SimSun 的粗糙字形。

- 数字（时间、金额、token）使用 `font-variant-numeric: tabular-nums`。
- 不引入 Web Font：中文包体过大，系统字体在各平台已足够好。品牌标题用一张 SVG 字标，彻底摆脱字体依赖。

### 4.2 字号阶梯（中文优化）

| Token | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| `display` | 32/44 | 600 | 空态大标题、引导页 |
| `title` | 24/34 | 600 | 页面标题 |
| `heading` | 20/30 | 600 | 区块标题 |
| `subheading` | 16/26 | 600 | 卡片标题 |
| `body` | 14/22 | 400 | 正文、表单 |
| `small` | 13/20 | 400 | 辅助说明、表格 |
| `caption` | 12/18 | 500 | 标签、时间戳 |
| `article-title` | 24/35 | 600 | 脚本正文标题（无衬线） |
| `mono` | 13/20 | 400 | 代码、ID、路径 |

规则：正文不小于 14px；中文行高 ≥ 1.55；每行 28–38 个汉字；标题不用斜体；英文与数字前后留 1/4 空格（用 CSS `text-spacing` 或手动）。

### 4.3 层级手段优先级

字重 → 颜色（fg/muted/subtle）→ 字号 → 间距。不靠下划线、不靠全大写、不靠彩色文字堆层级。

## 5. 间距、圆角、层级

### 5.1 间距

4 的倍数：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`。

- 组件内：4–12
- 组件间：12–24
- 区块间：24–32
- 页面边距：24（紧凑）/ 32（舒适）

### 5.2 圆角

| Token | 值 | 用途 |
|---|---|---|
| `radius-sm` | 4px | 徽标、输入框内元素 |
| `radius-md` | 8px | 按钮、输入框、卡片 |
| `radius-lg` | 12px | 面板、弹层 |
| `radius-xl` | 16px | 引导卡片、大容器 |
| `radius-full` | 999px | 头像、开关、胶囊 |

### 5.3 阴影（暖色，不用纯黑）

```css
--shadow-1: 0 1px 2px rgba(40, 36, 28, 0.06);
--shadow-2: 0 4px 12px rgba(40, 36, 28, 0.08);
--shadow-3: 0 12px 32px rgba(40, 36, 28, 0.12);
```

深色主题用 `rgba(0,0,0,0.5)` 并配 1px 内描边提亮边缘。

层级规则：卡片默认 `shadow-1` + `border`；浮层 `shadow-2`；模态 `shadow-3 + 遮罩`。同一屏不超过两级阴影。

## 6. 图标与插画

- 图标库：Lucide，线性，1.5px 描边，尺寸 16/20/24。
- 不用 emoji 做功能图标（跨平台不一致）；不用机器人、大脑、星光表意 AI。
- 状态图标语义固定：`○ 未开始 / ◐ 进行中 / ● 完成 / ⚠ 警告 / ✕ 失败`，在 UI 中用 SVG 实现。
- 空态插画：单色线稿 + 一个强调色块，尺寸 120–160px，不画人物。
- 品牌字标：待定名后做 SVG，单色可用。

## 7. 动效

| Token | 时长 | 曲线 | 用途 |
|---|---|---|---|
| `motion-fast` | 120ms | cubic-bezier(0.2, 0, 0, 1) | 悬停、按下 |
| `motion-base` | 180ms | 同上 | 展开、切换 |
| `motion-slow` | 240ms | 同上 | 面板、抽屉 |

原则：

- 只解释状态变化，不做入场动画表演。
- 运行中任务的进度用「呼吸」而非旋转 spinner（减少焦虑感）。
- 所有动效在 `prefers-reduced-motion: reduce` 下降为 0ms。
- 禁止：视差、粒子、渐变流动、打字机效果。

## 8. 组件视觉规格

### 8.1 按钮

| 类型 | 底 | 字 | 边 | 高度 | 用途 |
|---|---|---|---|---|---|
| Primary | accent | on-accent | 无 | 32/36 | 页面唯一主动作 |
| Secondary | surface | fg | border-strong | 32/36 | 次要动作 |
| Ghost | 透明 | muted→fg | 无 | 28/32 | 工具栏、图标按钮 |
| Danger | danger | on-danger | 无 | 32/36 | 删除确认 |
| Link | 透明 | accent | 无 | auto | 行内跳转 |

- 圆角 `radius-md`；水平内边距 12/16。
- 悬停：Primary 用 accent-hover；Secondary 底色转 `control`（不是 `sunken`，`sunken` 在深色下比页面还暗，会形成“洞”）。
- 禁用：`opacity: 0.45` + `cursor: not-allowed`，并给 tooltip 说明原因。
- 加载：文字替换为「处理中…」+ 左侧 12px 指示点，按钮宽度锁定不跳动。

### 8.2 输入框

- 高 32/36；底 `field`；边 `border-strong`；聚焦 2px `focus` 环 + 1px 内缩，聚焦时底转 `control`。
- 占位符用 `subtle`；`field` 上 `subtle` 已验到 4.60:1（浅色）/ 4.83:1（深色）。
- 错误：边 `danger` + 下方 12px 说明文字，不只靠颜色。
- 文本域行高 22，最小 3 行。

### 8.3 卡片

- 底 `surface`；边 1px `border`；圆角 `radius-lg`；内边距 16/20。
- 可点击卡片悬停升到 `shadow-2` 并轻微上移 1px（`motion-fast`）。
- 选中态：1px `accent` 边 + 左侧 3px 色条。

### 8.4 表格

- 行高 40（舒适）/ 32（紧凑）；表头 `caption` + `muted`；分隔线仅横向。
- 数字右对齐；状态列用徽标；操作列固定右侧。
- 超过 50 行启用虚拟滚动。

### 8.5 徽标 / 状态点

- 高 20；圆角 full；左右内边距 8；字号 12/500。
- 底色 13% 语义色叠在 `surface` 上，文字用语义色；实测最低 4.68:1（浅色 danger）。
- 运行中加 6px 呼吸点；离线用空心点。

### 8.6 检查器（右栏）

- 底 `surface`；左边 1px `border`；内边距 14；宽度 336。
- 卡片之间 12px；可折叠区块标题带 chevron。
- 宽度 336 默认，可拖到 420；拖拽把手 4px 热区。≤1280px 转为固定定位抽屉，默认关闭。

### 8.7 编辑器（脚本页）

- 最大宽度 720px 居中；行高 1.9；段间距 16。
- 引用标记 `[^1]` 用 `info` 色上标，悬停出浮层。
- 事实核查标记：底纹 `warn` 12%，左侧 2px 竖线，不改变文字颜色。
- 选中工具条：浮于选区上方 8px，`shadow-2`，圆角 full。

## 10. 落地方式

```
apps/desktop/src/styles/
├─ tokens.css        # 本文件 §3–§7 全部变量，唯一来源
├─ themes.css        # [data-theme="light"|"dark"] 映射
├─ base.css          # reset、排版基线、焦点样式
└─ utilities.css     # 少量工具类，禁止原子类泛滥
```

规则：

- 组件只引用 token，不写十六进制色值；CI 用 stylelint 规则 `color-no-hex` 拦截。
- 主题切换只改 `data-theme`，不重渲染组件树。
- 新增 token 必须在本文件登记并说明用途，否则 review 拒绝。
- Figma（或 Penpot）变量名与 CSS token 同名，避免翻译损耗。
