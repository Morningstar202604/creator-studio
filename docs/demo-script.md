# 演示脚本（录屏用）

## 0. 准备

- 启动：`node apps/daemon/dist/main.js --port 7878`
- 浏览器打开 `http://127.0.0.1:7878/`
- 已准备 3 个示例项目（选题 / 资料 / 复盘阶段各一）

## 1. 项目列表（20s）

1. 首页展示 3 张项目卡：阶段、进度条、标签、最近更新。
2. 顶部切到「列表」再切回「卡片」，说明两种视图共用同一份数据。
3. 搜索框输入「知识管理」，只剩一个项目；清空恢复。

## 2. 走通一条流水线（90s）

1. 进入「真实模型端到端验证」项目 → 左侧阶段条 → 选题页。
2. 展示已生成的三张选题卡（评分、风险）。
3. 资料页：展示可核查事实要点与资料缺口。
4. 脚本页：展示分节口播稿、字数与预估时长；选中一段 → 改写选中 → diff 对照 → 全部接受。
5. 分镜页：展示景别 / 画面 / B-roll / 上屏字幕表格。
6. 包装页：标题候选、简介、标签、合规提示。
7. 发布页：检查表全绿 → 导出发布包 → 结果列出 zip 内 6 个文件。

## 3. 可监督与可恢复（45s）

1. 工作台派活给「剪辑 Agent」：让它删除一个文件。
2. 运行停在「等你确认」，切到待办页。
3. 点「批准并继续执行」→ 回到运行状态，工具执行完成，事件流出现 tool.called / tool.result / run.finished。

## 4. 成本与自动化（40s）

1. 顶栏显示本月花费 / 预算，设置页可改三档预算。
2. 设置 → 模型：填入 API Key（写入本机密钥库）→ 测试连接返回延迟。
3. 自动化页：新建「每日选题」规则 → 立即运行 → 最近运行显示成功。
4. 资料库：跨项目产物检索、预览。

## 5. 复盘与主题（25s）

1. 复盘页：3 次数据回填 → 趋势图、完播率柱状图、环比。
2. 右上角切深色主题，再切「跟随系统」。

## 6. 命令面板（10s）

Ctrl+K 打开命令面板，输入项目名，回车直达。
