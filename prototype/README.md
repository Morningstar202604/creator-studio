# 交互原型（可点击）

单文件 HTML，无构建、无依赖，双击即可打开。

```
prototype/index.html
```

## 打开方式

直接双击 `index.html`，或：

```bash
python -m http.server 8080 --directory prototype
# 浏览器打开 http://localhost:8080
```

## 可交互的内容

| 操作 | 结果 |
|---|---|
| 左侧导航 | 切换页面（项目 / 任务 / 待办 / 资料库 / 自动化 / 设置） |
| 点项目行 | 进入项目工作台（脚本页） |
| 顶栏太阳图标 | 深浅色切换 |
| 顶栏右侧分栏图标 | 显示/隐藏右检查器；≤1100px 时变为抽屉 |
| URL 锚点 | `#projects` `#workspace` `#approvals` `#settings` `#runs`；深色加前缀，如 `#dark/workspace` |
| `Tab` | 第一个焦点是「跳到主内容」；所有可交互元素有 2px 强调色焦点环 |

## 已实现的设计约束

- 三栏布局：216px 导航 + 自适应主区 + 336px 检查器。
- 断点：≤1280px 检查器转抽屉且隐藏模型 chip；≤1100px 导航 196px、隐藏品牌副标题；≤1000px 导航 60px 图标栏、阶段栏从左侧竖排改为顶部横排条；最小 900px。
- 所有颜色取自 `docs/DESIGN-SYSTEM.md` §3.2 的 token；`scripts/check-contrast.py` 校验 122 项全部通过。
- 正文与正文标题用无衬线；衬线只保留在品牌字标。
- `prefers-reduced-motion` 下关闭动效与呼吸点。

## 已做的验证

用 Chromium 143（Playwright）在 1440×900、1100×800、900×800 三个视口截图，并跑了交互冒烟：

- 初始页 `projects`；点击「待办」后仅 `approvals` 可见；返回「项目」正常。
- 点项目行进入 `workspace`，检查器可见。
- 主题切换后 `data-theme=dark`，`body` 背景为 `rgb(20,20,19)`（= `#141413`）。
- 检查器开关两次可恢复原状。
- 1100px 视口下抽屉初始关闭，点按钮后 `inspector-open` 生效。
- 控制台无 error，无 pageerror。

截图存于 `docs/screenshots/`。

## 本轮已修复的问题

| 问题 | 现象 | 修法 |
|---|---|---|
| 深色输入框像"洞" | `--sunken` 用 `#101010`，比页面 `#141413` 还暗 | 拆出 `--field` `#262624`，输入框改用 `field` + `border-strong` |
| 悬停/选中态过暗 | 深色下 `--sunken` 当 hover 底，几乎看不见 | 新增 `--control` `#2E2E2B` 专供 hover/选中；`--track` `#171716` 专供分段槽 |
| 输入框边界太弱 | 深浅两套 `border-strong` 对输入底不足 3:1 | 浅 `#878277`、深 `#7C776E`，对 `field` 分别 3.27 / 3.41 |
| 900px 正文行宽过窄 | 左侧阶段栏仍占 168px，正文约 30 字/行 | ≤1000px 阶段栏改顶部横排条，正文恢复到 664px |
| 1200px 检查器挤压正文 | 1200px 仍三栏，正文只剩 384px | 抽屉断点从 1100 提到 1280 |
| 宋体正文发虚 | 15.5px SimSun 横细竖粗，长文阅读疲劳 | 正文改无衬线 15px/1.95；衬线只留品牌字标 |
| 危险按钮文字看不清 | 深色 `#E57B6D` 上放白字仅 2.84:1 | 新增 `--on-danger`，深色用 `#1A1010`（6.56:1） |
| 无可视焦点 | 键盘 Tab 看不到位置 | 全局 `:focus-visible` 2px 环 + 首焦点跳转链接 |
| 窄屏面包屑多一个 `›` | ≤1000px 隐藏一级后仍残留分隔符 | 改为隐藏前两个子元素 |
